ULOs

01 Demonstrate the impact of the history of web applications
development on current web-technology;

02 Design, construct and publish web-database applications;

[You are asked to do this]

03 Analyse and critique the key technological issues
confronting developers building web-database
applications;

04 Test the key features of programming languages which are
commonly used for developing web-database application;

05 Assess the MVC design pattern and construct a web-
database application using the MVC design pattern;

[The first thing when doing app dev is define the requirements]
[The first part of the A1 is to designing]

06 Apply, analyse and critique a professional approach
towards the development of web-database applications,
considering data privacy and cybersecurity aspects.
