SLIDE 9
========================================================================
Modularization in Software Development
1. Modularization on many different levels
- Project level, program level, function/procedure level (e.g. API, black box)
- printf() or scanf() is a function call
- A=B+C => the plus process is a function/operator (A=plus(B,C))
- There is a hierarchy of process (e.g. We don't need to write program in the
assembly language all the time).
2. No need to write programs at the lowest level:
- Abstraction, quality control, process hierarchy
3. Why do we need to modularize?
- Specialization
- Quality assurance

========================================================================
SLIDE 10
========================================================================
Modularization in Data Engineering
1. Provide a framework
- For specialization
- For quality assurance
- For abstraction
2. Separating each part of the entire data flow (or data pipeline)
- A separate process for data cleaning
- A separate process for dashboard
- And anything in between…

[Note] Doesnt matter who is doing it, the quality is the same, the customer can be assured the result is the same regardless the data is different
